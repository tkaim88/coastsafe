# CoastSafe Problem Definition

## Problem

People visiting beaches and coastal areas often need to check several sources before deciding whether conditions are suitable for their planned activities.

CoastSafe provides a single interface for viewing relevant weather and marine conditions for a selected coastal location.

## Target Users

Primary users include:

- Beachgoers
- Tourists
- Coastal residents
- Water-sports enthusiasts
- Outdoor activity planners

## User Problem

Users need an easier way to understand current coastal conditions without navigating multiple weather and marine information sources.

## User Expectations

A user should be able to:

1. Search for a coastal location.
2. Select a location.
3. View current weather.
4. View current marine conditions.
5. Review a short forecast.
6. Understand the conditions through a simple visual summary.

## Why CoastSafe?

The application focuses on the information most relevant to someone planning a coastal visit rather than attempting to reproduce a full meteorological platform.

## Phase 1

Phase 1 focuses on the React client-side experience and public API integration.

## Phase 2

Phase 2 will introduce a Flask backend and PostgreSQL database.

## Phase 3

Phase 3 will introduce authentication and user-owned features such as saved locations, favorites and reports.

## Scope Limitation

CoastSafe is an informational consumer application.

It is not intended to replace professional weather services, lifeguards, marine authorities, navigation systems, or emergency services.
