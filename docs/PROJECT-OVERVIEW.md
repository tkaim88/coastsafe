# CoastSafe — Project Overview

## 1. Project Name

CoastSafe

### Product Tagline

**Know Before You Go.**

---

## 2. Project Description

CoastSafe is a lightweight consumer-facing web application that helps people understand coastal conditions before visiting beaches and other coastal locations.

The application combines location search with weather and marine data and presents the results in a clean, readable interface.

---

## 3. Problem

Information about weather, wind, waves and other coastal conditions can require users to consult multiple websites or applications.

CoastSafe addresses this problem by bringing relevant conditions into one focused interface.

---

## 4. Target Users

The primary users are:

- Beachgoers
- Tourists
- Coastal residents
- Water-sports enthusiasts
- Outdoor activity planners

---

## 5. User Expectations

A user should expect to:

1. Search for a coastal location.
2. Select a location.
3. View current weather conditions.
4. View marine conditions.
5. Review a short forecast.
6. Understand the information quickly.

---

## 6. Phase 1 Goal

Build a working React client-side application that demonstrates:

- React component architecture
- JavaScript and JSX
- Dynamic API requests
- State management
- Loading states
- Error handling
- Conditional rendering
- Responsive styling
- Routing
- Git/GitHub workflow

---

## 7. Phase 2 Goal

Introduce a Flask backend and PostgreSQL database.

The backend will eventually provide application-specific data and business logic.

---

## 8. Phase 3 Goal

Introduce authentication and user-owned functionality.

Potential features include:

- User accounts
- Favorites
- Saved locations
- Reviews
- Reports
- Personal preferences

---

## 9. Product Growth Strategy

Phase 1 establishes the frontend and API integration.

Phase 2 establishes the backend and persistent data.

Phase 3 establishes the personalized user experience.

The architecture should therefore avoid tightly coupling the interface to the public API.
