# CoastSafe

CoastSafe is a consumer-facing coastal conditions application designed to help users make better-informed decisions before visiting beaches and other coastal locations.

The project is being developed as a three-phase Moringa School capstone.

## Phase 1 — React Frontend

The first phase focuses on building a responsive React application that consumes public weather and marine APIs.

Planned functionality includes:

- Coastal location discovery
- Weather conditions
- Marine conditions
- Forecast information
- Safety-oriented condition summaries
- Loading and error handling
- Responsive design

## Phase 2 — Flask Backend

The React application will be extended with:

- Flask REST API
- PostgreSQL database
- Persistent application data
- Backend API endpoints

## Phase 3 — Authentication & User Data

The application will eventually support:

- User registration
- Login/logout
- Authentication
- Favorite locations
- Saved locations
- User-generated reports
- User-owned data
